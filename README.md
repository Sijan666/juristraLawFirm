# Juristra - Law Firm & Legal Services Website

A modern, responsive Law Firm & Legal Services website built with Next.js, Tailwind CSS, and Lucide React.

## 🚀 Tech Stack
- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 📦 Features
- Responsive design for all devices
- Smooth infinite logo marquee
- Interactive statistics counter
- Modern legal services layout & components
